What to check before paying

  1. Check the size chart. Compare garment measurements with a piece you already own. For shoes, check what the seller’s size chart measures and compare the values in centimetres.
  2. Confirm the source listing. Check that the colour and size match and that LitBuy accepts the exact source URL before funding the order.
  3. Review warehouse photos. If QC photos are available, compare the labels, measurements and visible condition with the listing. Check the seller’s return deadline before approving shipment.
  4. Compare landed costs. Add domestic delivery, agent fees, international shipping and any applicable taxes to the item price. Compare quotes using the same destination and parcel dimensions, since the charge can depend on volumetric weight.

LitBuy spreadsheet FAQ

Where do the product buttons lead?

Both main buttons open CAFANS. Individual product links open their CAFANS listing pages. This is an independent shopping guide.

What if LitBuy rejects a source link?

Reopen the product page and check that you copied the seller’s original listing URL. If the agent still rejects it, ask support whether it accepts that marketplace before submitting payment.

Why is my final quote different from the table price?

The table shows reference item prices. Confirm the selected variant, exchange rate, agent charges and delivery costs when you request a quote.
